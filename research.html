Research & Project Details

1. Problem Statement

Hazardous gas environments pose significant risks to human safety, particularly in industrial zones, mining areas, and confined spaces. Traditional monitoring systems lack mobility, remote accessibility, and real-time cloud integration. There is a critical need for an intelligent mobile monitoring platform capable of environmental sensing, cloud-based analytics, and live surveillance.

2. Research Objectives

  • Design and develop a hexapod-based mobile robotic monitoring platform.
  • Integrate MQ-series gas sensors for real-time environmental detection.
  • Implement cloud-based data transmission using Firebase Realtime Database.
  • Develop a responsive web dashboard for remote monitoring and visualization.
  • Enable real-time camera streaming for surveillance applications.
  • Provide analytics including peak, average, and uptime monitoring.

3. Literature Review Summary

Previous gas monitoring systems primarily rely on static sensor nodes with limited remote access capabilities. Recent IoT-based solutions introduce cloud connectivity but often lack mobility and integrated surveillance. The proposed Hexapod Monitoring System addresses these limitations by combining robotic mobility, cloud integration, and real-time visualization within a unified architecture.

4. Proposed Methodology

The development process follows an embedded systems and IoT integration methodology. Hardware components are integrated with the ESP32 microcontroller. Sensor data is collected, processed, and transmitted via WiFi to Firebase Cloud. The web dashboard listens to real-time database updates and dynamically renders graphs, alerts, and analytics.

5. System Implementation

  • Sensor calibration and data acquisition using ESP32 firmware.
  • Secure WiFi communication with Firebase cloud services.
  • Real-time dashboard visualization using HTML, CSS, JavaScript, and Chart.js.
  • Alert logic implementation for hazardous threshold detection.
  • Historical data tracking and analytics generation.

6. Expected Outcomes

  • Accurate detection of hazardous gas concentrations in real time.
  • Stable and secure cloud communication architecture.
  • Responsive and user-friendly monitoring interface.
  • Enhanced situational awareness through live surveillance.
  • Improved safety monitoring solution for hazardous environments.

7. Research Contributions

  • Integration of mobile robotics with IoT cloud infrastructure.
  • Real-time analytics and visualization framework.
  • Modular and scalable system architecture design.
  • Combined environmental sensing and surveillance solution.

8. Future Improvements

  • AI-based hazard prediction using machine learning models.
  • Mobile application integration for remote alerts.
  • Autonomous navigation using additional sensor fusion techniques.
  • Advanced data analytics and long-term trend analysis.
  • Secure authentication and multi-user access control.
