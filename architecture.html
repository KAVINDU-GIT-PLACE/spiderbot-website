System Architecture

1. System Overview

The Hexapod Monitoring System is an IoT-based mobile robotic platform designed for real-time environmental gas detection and cloud-connected surveillance. The system integrates embedded hardware components with cloud services and a responsive web dashboard for remote monitoring.

2. Hardware Architecture

  • ESP32 (Main Control Unit) – Handles sensor acquisition, WiFi communication, and data transmission.
  • MQ-7 Gas Sensor – Detects Carbon Monoxide (CO) levels.
  • MQ-135 Gas Sensor – Measures overall air quality and environmental gases.
  • ESP32-CAM Module – Provides live video surveillance streaming.
  • Servo Motor System – Controls hexapod locomotion and movement.
  • Power Management System – Ensures stable voltage supply for sensors and control units.

3. Software Architecture

The firmware running on the ESP32 is responsible for real-time sensor data acquisition and WiFi-based communication. Sensor readings are transmitted to Firebase Realtime Database using secure cloud protocols. A web-based dashboard retrieves and visualizes this data dynamically.

4. Cloud Integration

Firebase Realtime Database acts as the central cloud repository. It enables bidirectional communication between the embedded system and the web interface. The cloud architecture ensures scalability, remote accessibility, and real-time synchronization.

5. Data Flow Model

Sensors → ESP32 → WiFi Network → Firebase Cloud → Web Dashboard → End User

6. System Operation Workflow

  • Environmental data is captured by MQ-series sensors.
  • ESP32 processes and formats sensor readings.
  • Data is transmitted via WiFi to Firebase Cloud.
  • The web dashboard listens for real-time database updates.
  • Graphs, analytics, and alerts are dynamically updated.

7. Design Advantages

  • Real-time monitoring capability.
  • Remote cloud-based access.
  • Scalable and modular system design.
  • Mobile robotic deployment for hazardous environments.
  • Integrated analytics and visualization platform.
