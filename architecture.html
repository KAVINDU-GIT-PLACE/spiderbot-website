System Architecture

1. System Overview

SpiderBot 2.0 is an IoT-based hexapod robotic monitoring system designed for environmental gas detection and real-time surveillance. The system integrates embedded hardware components with a cloud-based monitoring platform.

2. Hardware Architecture

  • ESP32 (Control Unit) – Handles movement and sensor coordination
  • MQ-7 Gas Sensor – Detects Carbon Monoxide (CO)
  • MQ-135 Sensor – Measures air quality
  • ESP32-CAM – Provides live video surveillance
  • Servo Motors – Controls hexapod movement

3. Software Architecture

The system uses ESP32 firmware for sensor acquisition and WiFi communication. Sensor data is transmitted to Firebase Realtime Database, where it is accessed by a web-based dashboard for visualization.

4. Data Flow

Sensors → ESP32 → WiFi → Firebase Cloud → Web Dashboard
